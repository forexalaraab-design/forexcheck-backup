## 3. كيف يعمل المصنع (نظرة عامة)

### سير العمل:
1. **cron-job.org** (كل ساعة) يضرب الويباب `?action=publishNow` — أو **موقت داخلي** `setupTrigger()` كل `PUBLISH_INTERVAL_MINUTES` دقيقة.
2. `runPublishNow()` يجلب RSS من مصادر (`DailyFX` وغيره) — **بحد يومي** `MAX_DAILY_POSTS: 4`.
3. يلتقط أحدث خبر غير منشور (تذكر `seen` في PropertiesService لمنع التكرار).
4. يجمع صوراً مرشحة ويختار أفضل صورة، يعالجها (حجم + علامة مائية باللوغو).
5. **Gemini** (نماذج flash-lite) يكتب المقال العربي عبر `generateArabicArticle()` بأسلوب بشري + SEO.
6. يُنشر على Blogger REST API مع تصنيفات + ميتا وصف مخفي (div).
7. بعد النشر: **Buffer** (فيسبوك/تويتر) + **Telegram** + **IndexNow** + **Bing SubmitUrl**.
8. يخزن العنوان في `seen` ويزيد العدّاد اليومي.

### نقاط التحكم في `CONFIG` (أعلى المصنع):
- `MAX_DAILY_POSTS: 4` — حد النشر اليومي (الكمية).
- `PUBLISH_INTERVAL_MINUTES: 180` — تواتر الموقت الداخلي.
- `MAX_ITEM_AGE_HOURS: 48` — تجاهل الخبر الأقدم من 48 ساعة.
- `BING_API_KEY` — مفتاح إرسال Bing.
- `BUFFER_ENABLED/BUFFER_TOKEN/BUFFER_ORG` — المشاركة الاجتماعية.
- `TELEGRAM_BOT_TOKEN/TELEGRAM_CHAT` — بث تيليجرام.
- `GITHUB_TOKEN/GITHUB_REPO` — استضافة الصور وملفات IndexNow.

### إجراءات الويباب (doGet action):
| action | الوظيفة |
|---|---|
| `publishNow` | نشر خبر جديد |
| `resetAndPublish` | مسح الذاكرة ثم نشر |
| `deleteAllPosts` | حذف كل المنشورات (يتطلب key) |
| `setupTrigger` | إنشاء الموقت الداخلي |
| `clearTriggers` | حذف الموقت الداخلي |

## 4. قواعد حاكمة (مهمة جداً — من AGENTS.md)

1. **Blogger API v3 لا يرفع القوالب** (لا مورد themes). تعديل القالب = يعدّ الملف ثم **المستخدم يرفعه يدوياً** عبر: المظهر → سهم بجوار تخصيص → استعادة.
2. **محتوى ودجت HTML في القالب** يجب أن يكون داخل `<![CDATA[ ... ]]>` وإلا يحفظ Blogger الودجت فارغاً.
3. **الصور** تُرفع على نطاق Google عبر `?action=uploadImage` (base64 → رابط `lh3.googleusercontent.com/.../s0/...`). لا `data:` URI ولا روابط خارجية.
4. **Bing SubmitUrl**: `POST https://ssl.bing.com/webmaster/api.svc/json/SubmitUrl?apikey=KEY` بجسم `{"siteUrl":"https://forexcheick.blogspot.com/","url":"<postUrl>"}` — نجاح = 200.
5. **تحديث منشور بدل مكرر**: `?action=publishBroker` مع `path` بشرطة مائلة بادئة `'/2026/08/xx.html'`.
6. **لا سكربت JS إضافي** في الموقع — حلول HTML/CSS خالصة (إلا للضرورة).
7. **أي تعديل قالب/نشر** → تحقق حي (200/صور/وسوم) ثم عرّف للإصدار التالي.

## 5. كيفية النشر عبر clasp (سير العمل الدقيق)

1. المصنع المصدري: `forexcheck-blogger-factory.gs` على سطح المكتب.
2. نسخ إلى `clasp_push/الرمز.js`:
   ```
   Copy-Item "forexcheck-blogger-factory.gs" "clasp_push/الرمز.js" -Force
   ```
3. فحص الصحة:
   ```
   node --check "clasp_push/الرمز.js"
   ```
4. إنشاء سكربت نشر من آخر نسخة:
   ```
   Copy-Item deploy_vNN.js deploy_vNnext.js
   ```
5. تعديل وصف الإصدار داخل `deploy_vNnext.js`:
   ```
   description: 'vNN: وصف مختصر'
   ```
6. تحديث التوكن ثم النشر:
   ```
   node -e "const fs=require('fs'),path=require('path');const c=JSON.parse(fs.readFileSync(path.join(process.env.USERPROFILE,'.clasprc.json'),'utf8'));fs.writeFileSync(path.join(process.env.TEMP,'opencode','fc_fresh_token.txt'),c.tokens.default.access_token,'utf8');"
   node deploy_vNnext.js
   ```
7. النجاح = `DEPLOYED vNN HTTP 200`.

> **آخر إصدار منشور**: v73 (قيمة مضافة + Bing + حد يومي + أسلوب بشري).

## 7. بنية القالب (forexcheck-theme-investing.xml)

- **الترويسة**: `header` + شريط أسعار (ticker) + قائمة تنقل من `CONFIG.nav`.
- **main**: `main-sect` → Blog1 → (منزل/تصنيف/مقال منفرد) + pager.
- **sidebar**: ودجت HTML5 (CTA تيليجرام) + HTML6 (الوسطاء الموصى بهم) + HTML1 (بحث).
- **الفوتر**: `footer-grid` = 3 أعمدة (1.6fr 1fr 1.2fr): نبذة + صفحات + روابط سريعة.
- **أقسام الودجت الخفية**: `fx-logo-sect`, `fx-adsense-sect`, `fx-config-sect` — تظهر في التخطيط للتحكم.
- **JS القالب**: `fxFeedImages` (صور البطاقات من أول `<img>` في RSS)، `fxApplyConfig` (تطبيق الإعدادات)، الوضع الليلي.
- **config المزدوج**: مصفوفتا `FX_DEFAULTS` و config الفعّال في `fx-config-sect` — يجب تحديثهما معاً.

### قواعد القالب المشتركة:
- أي تعديل يُطبّق في **الملفين معاً**: `investing` + `restore-logo`.
- وسوم `<b:widget>` متوازنة: 7/7، `<b:section>` 7/7، `<b:includable>` 14/14.

## 10. مشاكل معروفة وحلولها

1. **عدم فهرسة جوجل**: سببه كان الكمية الهائلة (25-32 مقال/يوم). الحل: الحد 4/يوم (v71) + إشعارات Bing (v72) + قيمة مضافة (v73).
2. **زر «الصفحة الرئيسية» أسفل المقالات**: ودجت PageList في Layout — يُحذف يدوياً + CSS في القالب.
3. **صور بطاقات بلا صورة**: `fxFeedImages` يقرأ أول `<img>` من RSS — استبدل أول صورة برابط Google أبيض.
4. **JSON-LD مكرر**: أرسل محتوى المقال نظيفاً (بدون ld+json/div خفي) — الويباب يضيفهما تلقائياً.
5. **`data:` URI لا يفهرسه Google**: ارفع الصور عبر `uploadImage` أولاً ثم ضع الرابط.
